# SAVAGE - Creative Developer Portfolio

A modern, responsive portfolio website showcasing creative development work with a cyberpunk-inspired design.

![Portfolio Website](https://via.placeholder.com/800x400/0a0a0a/00ff41?text=SAVAGE+Portfolio+Website)

## 🚀 Features

- **Modern Design**: Cyberpunk-inspired theme with neon green accents
- **Responsive Layout**: Fully responsive design that works on all devices
- **Smooth Animations**: Loading screen, scroll animations, and interactive elements
- **Navigation**: Smooth scrolling navigation with active section highlighting
- **Project Showcase**: Dynamic project gallery with filtering capabilities
- **Skills Display**: Visual representation of technical skills
- **Contact Form**: Functional contact section
- **Dark Theme**: Eye-friendly dark theme throughout

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and modern HTML features
- **CSS3**: Advanced CSS with custom properties, animations, and transitions
- **JavaScript**: Vanilla JavaScript for interactivity and dynamic content
- **Font Awesome**: Icon library for UI elements
- **Google Fonts**: Custom typography (Inter & Space Mono)

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd profile-website/p3
   ```

2. **Run locally**
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Or using Node.js
   npx serve .
   
   # Or using PHP
   php -S localhost:8000
   ```

3. **Open in browser**
   Navigate to `http://localhost:8000`

## 🔧 Customization

### Changing Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #00ff41;
    --secondary-color: #00cc33;
    --accent-color: #ff0080;
    /* ... other variables */
}
```

### Adding Projects
Edit the projects section in `index.html` and update `script.js` accordingly.

### Modifying Skills
Update the skills section in both HTML and JavaScript files.
